# 紅髮女騎士：八方向步行製作指令 v1.2

本文件可直接交給 AI 執行。先讀角色總索引 character-record.json，再取得文末要求的附件；只有文字、沒有實際母版時，不得憑記憶重畫。

## 目前基準與工作範圍

- 角色：red-knight-female，紅髮編辮高馬尾女騎士。
- 形象原畫／高細節靜態：v1-0-1/character.json 的 references；用途是設計核對，不能單憑高解析原畫生成遊戲動畫。
- 遊戲八向靜態：v1-0-1/runtime/idle.json 與 idle.png，方向與比例基準。
- 已確認右向步行：walk-right-v7/animation.json 與 walk-right.png。v0.7 是造型與動作對照基準，保留原檔，不用重新生成右向代替後續七向。
- 已確認視覺：右向v0.7、正面walk-down-v1、背面walk-up-v1，各8幀，共24／64幀；接地校準仍獨立記錄。剩餘5方向40幀，左向先做四關鍵姿勢。不得把左右鏡像或靜態圖稱作完成動畫。
- 正面參考：walk-down-v1/animation.json、walk.png。原檔保留；新方向參考其裝備與比例，不照搬朝向。
- 這是美術／動畫素材流程，尚未替換正式遊戲。不要擅改遊戲存檔、連線、碰撞或戰鬥。

舊production-standard.json與早期guide中的「頭像素完全固定」「左向直接鏡像」屬先前試驗，不可蓋過本文件的微律動與固定持手規則。新方向須重建自己的遮罩，不能複製右向座標。

## 可直接使用的主指令

你正在為《類天堂》製作同一位紅髮女騎士的八方向步行。這輪只製作【目標方向】，先完成4個關鍵姿勢供檢查，再補足8幀；不要一次混合男女角色或多個角色。

嚴格沿用附件的角色身分：紅色編辮高馬尾、亮銀板甲、紅內襯、黑絲襪、既定腿甲與靴型，無長披風。解剖右手只持一把直劍，解剖左手持盾。角色轉向後裝備可以被身體遮住，但不能換手。側面看到盾內面時保留內面，不為了展示紋章把盾轉正面。

以該方向的遊戲靜態圖定視角、頭身比例與裝備透視；以已確認右向v0.7核對盔甲設計、清晰度與步態品質。約35度俯視、固定投影與鏡頭，不因方向或姿勢改變縮放。素材每格128×128 RGBA，地面原點(64,112)。128是畫布，不是人物身高；人物可見輪廓沿用現有約96px級含馬尾，不能每格自動塞滿畫布或放大角色。

每幀繪製完整人物姿勢，不准切下靴子／腿再平移、拉伸冒充步行，也不准用整張角色水平移動代替動作。近腿／遠腿是相對鏡頭的遮擋身分，必須另有固定的解剖左腿／右腿標記；換方向後不可沿用「右腿永遠在近側」的假設。不要只用相位標籤宣稱腳畫對，必須追蹤髖、膝、踝、腳跟、腳尖。

八幀相位：
F1右腳前伸接地 → F2右腳承重下沉 → F3左腳經過 → F4左腳抬起前送 → F5左腳前伸接地 → F6左腳承重下沉 → F7右腳經過 → F8右腳抬起前送 → 自然接回F1。
這是動作關係，不是讓八方向都複製同一張側面腿。上下與斜向須有正確縮短、遮擋及腳掌朝向；F1/F5的左右支撐關係互換，不能只畫相同輪廓。

胸甲保持連續的外凸曲面，先分亮／中／暗三大面，不能出現像胸部凹陷的黑洞、矩形缺口或胸肩斷層。黑色頸領連好下巴與胸甲，不得出現橫向黃條或額外膚色碎片。保留身形，不為修甲改胸部大小或肩腰比例。

握劍手、握柄、護手、刀根、刀身、劍尖必須連成同一把完整直劍；不得分叉、斷節、雙刀或殘留舊刃。盾牌在正確遮擋層，邊緣連續、形狀與透視一致，不得穿過前臂或刀身。

頭部維持該方向的臉型與朝向，不逐幀重新設計，不獨立點頭。沿用小幅承重律動：右向參考的頭部垂直位移為[0,1,0,0,0,1,0,0]素材px；其他方向依同一承重節奏核對，不把右向補片座標硬套過去。髮根隨頭，髮中段銜接，保留現有髮尾幅度。持裝備手臂只需自然小幅反向連動，不甩劍、不大幅扭轉胸甲。

嚴格保持同一畫布、調色與光源。禁止逐格auto-fit、不同插值、混合像素尺度或任意銳化。若先生成放大局部素材，必須記錄共同裁切、縮放與合成方式，最後以原生輸出尺寸及手機實際顯示尺寸驗收；不得稱為原生逐像素手繪。

若只修局部，先列明「允許改動區」與「保護區」，生成候選後只採允許區，其他RGBA保留。保護區應以已確認的完整構件為單位：不得把一小塊舊金色握柄硬鎖、卻讓新手套與刀身各自換位置。舊像素可能本來就有錯，修正前先檢查，不能把「沒變」當成「正確」。

## 方向規格與製作順序

統一使用螢幕方向名稱，順序：down（正面）、down-right（右前）、right（右側）、up-right（右後）、up（背面）、up-left（左後）、left（左側）、down-left（左前）。這些是朝向，不是光源方向。

右向、正面與背面視覺已確認。建議接續left→down-right→up-right→up-left→down-left，一次只做一向，避免多向錯誤同時累積。順序是製作建議；若使用者指定別向，以使用者為準。

左右不可直接水平鏡像交付：那會交換持劍／持盾的解剖手。鏡像只能作姿態草稿，必須補正裝備、非對稱細節、光源與遮擋，再獨立驗收。

## 每一向的交付關卡

1. 先展示該向靜態、已確認右向參考、F1/F3/F5/F7四個關鍵姿勢。確認同一角色、支撐腳與遮擋再補F2/F4/F6/F8。關鍵姿勢是製作中的檢查，不代表先生成整套再任意重排。
2. 八幀完成後提供每幀透明PNG、1024×128橫排圖集、animation.json、逐幀對照圖、原地循環和實際前進預覽。診斷用左／右腿異色標記另圖保存，不得烘焙進成品。
3. JSON至少包含角色ID、版本、state=walk、direction、cell、frameCount、frameOrder、每格裁圖、ground anchor、frame durations、解剖手腳說明、來源和驗收狀態。未知關節座標應標待人工核對，不能捏造自動量測。
4. 先完整全身驗收，再看胸甲／頸口／完整武器／盾／髮尾放大，不能只看局部裁圖就漏掉整段刀身。
5. 正常循環F1→F8→F1，不可往返播放。接縫另播F7→F8→F1→F2一次，停在F2，避免把F2跳回F7當成循環問題。
6. 提供正常速度、半速、逐幀、原尺寸及2倍；以遊戲實際顯示大小作主要判斷。完成一向後加入方向轉換測試，再開下一向。

## 數值與接地規則

- 右向參考為48素材px／完整步行週期，8×100ms＝800ms；預覽60素材px/s時對應這組節奏。這些是試場素材單位，不可直接寫成正式遊戲世界速度。
- 動畫相位由實際移動距離累積；暫停則不前進，改速度不能重設腳步。原地循環可用相同虛擬距離驅動。
- 支撐腳著地期間，在實際前進畫面應大致停留在世界地面位置；在原地圖格中，腳會相對身體向後移，不是每格固定同一局部x。腳尖離地與承重切換要連續。
- 新方向的螢幕投影步幅需量測，不能一律把右向48px當上下／斜向螢幕位移。對角線世界移動需避免額外變快；本輪先記錄校準結果，不修改正式移速。
- 所有幀保留同一地面原點。單腳抬起不等於整個人物原點向上搬；斜向兩腳接地投影y可以不同，不能用圖片最低像素或刀尖當腳底。
- 角色圖像外框、身體尺寸、腳底錨點與碰撞區分開；盾牌和武器較寬不能直接放大碰撞半徑。

## 問題回顧：已遇到什麼、如何避免

| 已遇問題 | 成因／教訓 | 下一次要求 |
|---|---|---|
| 動起來腿甲變細、裝備換款 | 整體重生成及不一致縮放 | 固定同角色母版；一次一角色一方向，局部修補不重生全身 |
| 腳突然交換、像同腳滑行 | 解剖左右身分與相位不連續 | 追蹤關節與支撐；核對半週期和F8→F1，不靠加幀掩蓋 |
| 人物浮起、轉向跳動 | 用外框／刀尖對齊、各格auto-fit | 同地面錨點；獨立記錄腳接觸點與圖像外框 |
| 腿動、上身像固定平移 | 只處理下肢；頭被完全鎖死 | 先保穩定臉型，再小幅承重連動，不重畫臉或亂點頭 |
| 頸部黃橫條 | 固定頭與逐格頸補片沒接好 | 頸領視作完整接合面；核對全部8格與頭部微位移 |
| 胸甲像胸部凹陷 | 胸肩／胸腰明暗缺口與碎片合成 | 胸甲維持外凸連續曲面，不用暗洞表示裝甲層次 |
| 刀刃不完整、局部斷裂 | 新刀位置和舊保護區不一致 | 手套到劍尖整體銜接；檢查完整刀線，不能只驗刀尖 |
| 金柄碎裂、手套接不上 | 舊金色像素硬鎖，新手套各自生成 | 以完整構件修補，固定持手，不逐色切碎接縫 |
| 雙刀、舊刀殘影或鞋尖誤採 | 遮罩走廊誤含舊刃／腿／鞋 | 清楚區分新舊刀與可見腿，實看遮擋；鞋尖不能參與刀線擬合 |
| 盾緣跳動、盾穿手劍 | 盾形與遮擋層級沒固定 | 一方向一致盾形，依方向列前後層，手劍前方像素保護 |
| 馬尾接縫或髮量跳變 | 髮根與髮尾分區動作銜接差 | 髮根跟頭，中段銜接；不借修接縫改髮型或增加擺幅 |
| 測試都過仍然破圖 | 只驗區外未變、alpha連通 | 另外查胸甲結構、頸色、刀身路徑、手盾遮擋與完整全身 |

## 必須分開的三種驗收

A. 檔案／程式：尺寸、RGBA、完整格數、裁切、順序、錨點、播放及下載正確。不能單靠這些宣稱美術通過。
B. 像素保留：對已確認保護區逐像素核對，輸出遮罩和差異數；骨架／武器遮擋區需如實說明，不能宣稱隱藏腿完全不變。
C. 視覺／動作：同一人、黑絲／腿甲／靴型、凸胸甲、完整單劍、固定持手、盾透視、頸接合、髮量、步態、接地、循環與轉向。必須在實際尺寸人工檢查。

全角色alpha連通不等於刀身完整：身體／腿／盾可能繞路把斷刀接成同一塊。需沿刀身實際走向檢查從刀根到劍尖的連續輪廓；銀色連通路徑只是輔助，不能取代目視。

產出報告要列「已確認」「仍待確認」「未製作」。技術通過不自動提升為使用者美術確認，不把某一向的通過擴大為八向已完成。

## 局部修正追加指令模板

保留【版本／方向】的【已確認部位、影格順序、比例、步態】。只修【部位與問題】，允許修改【明確區域】；保護【完整構件／原圖像素】。涉及頸／胸／手柄接縫時，以完整接合面處理，不能把舊碎片當不可更動的正確母版。生成後僅採允許區，提供逐幀前後對照、保護區RGBA差異與完整全身循環；若候選改了裝備或比例則拒收，不用逐格縮放補救。

## 背面製作補充

背面up時解剖右手/腿在畫面右側、左手/腿在畫面左側；盾內面可見。向上走時支撐腳在身體局部會向畫面下方移動。地面原點固定，不代表每個相位的支撐靴底都強行對齊同一像素列；那會消除步態的投影位移，增加前進滑步。先定共用鏡頭/比例與各相位接觸點，再校準世界前進；不能用各格最低腳尖重新對齊掩飾差異。

## 左向製作補充

left視角近側為解剖左臂盾/左腿，遠側為解剖右手劍/右腿；盾外側紅面可見，右手劍可被身體或盾自然遮住，不代表換手。不要直接翻轉右向動畫。向左走時支撐腳在人物局部向右移動，需核對近遠腿遮擋、F1/F5半週期及步幅。
