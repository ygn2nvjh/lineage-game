# 角色步行製作規格與提示模板 v1

狀態：依紅髮女騎士右向8幀 v0.1→v0.2診斷整理，仍是工作規格，未經多角色驗證。提示詞提高約束，不能保證生成器照做。每次必須核對「實際圖片」，不能把預定動作名稱當成驗收證據。

## 先鎖什麼

1. 角色ID/母版版本與SHA、方向、近側/遠側腿、慣用手與裝備。右向示範：解剖右腿=鏡頭近側，右手單劍、左手盾；換方向須重新判斷，不能把畫面左/右直接當解剖左/右。
2. 畫布/根點/視角/像素尺度/材質色階。女騎士目前128×128透明格、地面根點64,112、含馬尾約96px。根點不等於每幀所有腳掌都貼地；遠腳有深度差，擺動腳應離地。
3. 八格姿勢導引與每隻腳的膝、腳跟、腳尖路徑。先分清接地/承重/經過/前送，再畫裝備。近遠腿可在診斷圖用橘/青標示；成品沿用原材質，不把腿永遠染成不同色。
4. 一次循環移動多少世界距離；由支撐腳在角色座標下往後移動量推估，不能用PNG寬度或刀尖決定。

## 八格規格

| 格 | 右腳 | 左腳 |
|---|---|---|
| F1 | 前伸接地 | 後方離地準備 |
| F2 | 承重、腳掌相對根點往後 | 後方抬起 |
| F3 | 支撐、位於身體下方 | 彎膝經過 |
| F4 | 後方支撐、準備離地 | 前送、尚未接地 |
| F5 | 後方離地準備 | 前伸接地 |
| F6 | 後方抬起 | 承重、腳掌相對根點往後 |
| F7 | 彎膝經過 | 支撐、位於身體下方 |
| F8 | 前送、尚未接地 | 後方支撐、準備離地 |

這是簡化的相位分工，接地交接可能短暫雙腳支撐；不要求某一張圖只有一隻腳碰地。固定解剖身分，兩腿遮擋順序不能隨「誰在前」互換。F8右腳已在前方，F1只是落地，不能從後方瞬間跳到前方。

## 可重用生成提示（填入角色與方向）

> 嚴格使用附圖【角色母版ID與版本】的髮型、鎧甲、腿甲、靴型、黑絲/內襯、武器與盾牌；不重新設計裝備。製作【方向】八幀完整角色步行，按附帶姿勢導引依序F1至F8排列。固定近側為【解剖哪條腿】、遠側為【哪條腿】，同一條腿保留前後遮擋與材質明暗。F1–F4由右腿承重、左腿由後向前擺；F5–F8相反。特別核對F6：遠側支撐腳著地、近側擺動腳離地；F8：下一次接地的腳已在前方，F8接F1只落地。若方向不同，先依解剖身分重新表述近遠側，不能照抄「遠側承重」。膝蓋適度彎曲，沒有跑步抬膝；腳在經過姿勢靠近身體下方。相同畫布、鏡頭、角色尺度、光源、像素色塊，預留一致透明邊界；每格畫完整人物，不切腿位移。頭肩腰保持穩定，保留小幅承重起伏，不用逐格縮放修比例。僅一把武器，持手固定。沒有文字、地面陰影、參考線或背景。不得將第一半週期複製冒充另一隻腳的半週期。

## 針對錯格的修正提示

> 只修【F幾】完整姿勢，附前後兩幀、同一母版及關節導引。固定【哪條腿】支撐，其腳跟應在【座標】、腳尖【座標】、地面高度【y】；【另一腿】膝蓋【座標】、腳跟【座標】，須離地。保持頭、肩、腰位置、腿甲厚度、靴長、劍盾與全身尺度，禁止換支撐腳。成品仍需逐像素/關節核對；座標文字不是約束必定成功的保證。

## 反例與已遇到的失敗

- 「左右交替」太模糊：模型常讓亮腿每次都承重，將亮/暗誤當前/後腳。
- 同批兩個passing仍可能同腳；F1/F5剪影相近並不證明身分交換正確。
- 單格高解析補畫會換腿甲、改靴厚/頭身，縮到同高仍不一致；不可逐格auto-fit掩蓋。
- 先圖集打包再標記「右腳支撐」是循環論證；標記必須來自可見膝/脛甲/靴遮擋，遮住的部位標低信心。
- 同根點只消除整張漂移，不會自動消除接地腳滑動。
- 高清像素風縮圖不是原生像素手繪；最近鄰也無法補回正確姿勢與裝備。輸出仍需在最終尺寸整理。

## 統一輸出與校準

優先整組同來源尺寸和同採樣方法；補畫需先將整個來源畫布正規化到同規格，再按頭/肩/髖等身體定位核對，不能用外框高度自動撐滿。整張平移可用於根點定位，不可拿平移腳部冒充動作。透明像素RGB清零只作技術清潔，不改可見角色。

必留：未改母版、原始生成來源、逐格PNG、圖集、排序JSON、地面根點、人工關節與信心、支撐段、來源正規化規則、SHA及候選/驗收狀態。圖集RGBA逐格等於單圖。不要覆寫已鎖存版。

## 驗收清單（不能跳過）

1. 原生顯示大小看完整循環；2倍/放大只找問題。
2. 診斷遮罩只看腿；橘線右腿、青線左腿，逐幀追蹤髖、膝、腳跟與腳尖。這只是分析，不是拆腿製作成品。
3. 比較F1/F5、F2/F6、F3/F7、F4/F8；半週期應交換支撐，但不直接鏡像非對稱裝備。
4. 檢查全部8個轉換，包含F8→F1；列出腳跟躍移大的段。對約96px人形，18px是本次「待看」門檻，非業界標準或一律不合格。
5. 支撐段估算：世界腳跟變化 = 本格腳跟x − 前格腳跟x + 每格根點前進量；應接近0。人工標點約±2px，差值誤差可達±4px，不能把估算當精準物理測量。腳身分判錯的支撐段須先排除並顯示原因。
6. 配合實際前進測試，調速時依移動距離選格；試場stride需換算正式世界倍率才能整合。
7. 母版對照頭身、肩/腰位置、腿甲寬、靴長、髮量、持手/單武器、盾形；PNG尺寸相同不代表造型一致。
8. 接地與關節通過後再微調髮尾、武器、呼吸和起伏。所有技術測試通過仍不能自動標記「美術通過」。

## 目前結果（可回查，不是成功承諾）

舊版F6/F8的支撐身分與相位矛盾，F8→F1近腳跟位移人工估算約31px。v0.2改成遠腿承重、近腿前送，接縫估算約5px；可判讀支撐段最大橫向漂移估算由13px降到4px。仍有F7→F8擺腳約21px與F2→F3遠腳遮擋/標點不確定，應持續目視驗收，不宣稱動作全修好。可重用的是檢查方法，這份提示尚未證明能讓每次生成一次成功。

## 上半身動作局部製作補充（v0.3工作規格）

先P0手臂與武器連動，再P1承重格軀幹約1px，最後P2髮尾延遲；各階段都存圖集供切換。這輪不再擴大腿部範圍。

生成器沒有保證區域外不變；必須明確輸出遮罩並合成：先保留基底，再只採修改區，逐像素檢查區外差異=0。臉/髮根/腿甲/靴子保護區固定。劍原本遮住腿的位置屬武器區，要先分清舊刀刃與腿，不能讓殘影變成雙刀；也不能採用新生成腿/鞋碰巧落在武器修改區內的像素。檢查每格單連通區、刀尖軌跡和附著關係。不能用「連通」單一條件就證明只有一把刀。

姿勢小幅運動不代表可任意換裝；生成補片依然可能改鎧甲表面，需原尺寸看造型。P1約1px是目標，肩甲亮面重心只能作代理估算；P2延遲一格也是目標，最終要看循環，不宣稱提示已精準控制物理。

局部提示：只改【部位】及【指定幀】，附同一母版與已通過步態。肩肘腕與單劍連續、持盾幅度更小。保持原畫布與像素尺度、裝甲形狀與厚度，禁止更動頭身、腿與靴。承重F2/F6小幅下沉，通過格相對較高；髮根固定，髮尾落後身體交換。採用前要做修改區外RGBA比對、腿/靴保護區比對、F8→F1與劍尖路徑核對；驗收前不得蓋過鎖存版。
