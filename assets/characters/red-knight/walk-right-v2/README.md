# 右側步態診斷與候選 v0.2

入口：/art-walk-diagnosis.html?v=2。原靜態v1.0.1、舊步行v0.1與正式遊戲均保留。

動畫PNG每格128×128、根點64,112，可見約93–95px。來源為生成完整角色後整個來源畫布正規化到384×512，共同77×102最近鄰採樣與26,16偏移；沒有逐格外框auto-fit、沒有切腳平移。仍非原生逐像素手繪，不能宣稱裝備像素完全等同母版。

本次以近右/遠左腿姿勢導引生成，未依生成順序盲播；按可見解剖關係挑選完整姿勢，錯支撐的候選拒採。6格同一主sheet、1格同尺寸修正sheet、1格單張補畫先正規化整個畫布。實際prompt、失敗例、使用來源在generation-prompts.json及animation.json。

landmarks.json為人工標點（約±2px；遮擋處低信心）；diagnosis.json是依標點計算，不是圖片自動辨識人體。接縫右腳跟約31→5px；可信支撐段最大橫向漂移估算13→4px。F7→F8近腳擺動與F3遮擋仍需驗收，沒有標成美術通過。

步幅48來源像素/輪，預設60px/s，一輪800ms。試場值需再按正式世界倍率換算；只改播放速度不能修錯腿。

下個角色使用production-guide.md：固定母版/解剖腿身分/關節導引、生成提示、反例、支撐殘差、全部8轉換與F8→F1驗收、輸出規範。這份工作規格未經多角色驗證，提示不能保證一次成功。
