# 紅髮女騎士右側步行候選 v0.1

母版：../v1-0-1/character.json；不覆蓋八向靜態或正式角色。

8張完整角色PNG與1024×128透明圖集；每格128×128、地面根點64,112。可見約91–94px含馬尾；母版96px。前四格右腳支撐，後四格左腳支撐。生成候選再技術縮圖，非原生逐像素手繪、非拆腿平移，不能以技術通過宣稱裝備逐像素一致。

動畫相位依已移動距離計算，每輪64來源像素；80px/秒時一輪800ms。這是試場值，不是正式遊戲速度；半速同時降低移速與步頻。

calibration.json記錄母版SHA、各格alpha連通區、輪廓邊界與SHA。animation.json記錄方向/裁圖/原點/支撐腳及生成來源。不同來源圖先作來源解析度正規化，沒有按每格外框自動填滿；肢體與裝備一致性仍需人工驗收。

頁面/art-walk-right.html提供同倍率靜態對照、原地播放、逐格/半速/放大、道路/草地/簡化石地、依距離步頻前進、母版淡影八格並排與透明圖集下載。
