# 暮色墓園動作試場（待實機美術驗收）

入口/art-play.html，獨立本機美術沙盒，無WebSocket、無雲端身分/存檔讀寫。正式/play仍adventure0.1.6，未替換正式人物/怪物圖集、傳輸協定或經濟判定。

使用者本輪授權：先修女角側面/背面頭髮長度一致（肩胛附近），骨白彎刀骷髏恢復破褲裝；再做實際場景移動與攻擊。女亮銀紅、男黑鋼藍、無長披風/頭盔/盾牌外觀，角色顯示高度沿ART_MOTION。新骷髏各影格保留棕色破短褲、繩帶、兩個褲管與彎刀。

男女及骷髏各24格：3向待機、2受擊、1倒下、6格側步、3格朝前/3格朝後步行、6格側向攻擊。左向鏡像，未完成八方向攻擊；橫/縱出招共用本輪側向素材但使用正式接觸時機。走路相位沿用World.actorState依位移推進，非固定站姿抖動。圖集經prepare-art-play.py依透明邊界/行分界打包到112px身體基準，runtime每張960x640，來源無損WebP保留。

src/art-play.mjs使用正式Game/createState/derive與World；地圖為獨立960x1100墓園，入口和出生點依法驗證、墓碑/墓室碰撞、三個普通骷髏點位。測試裝備用正式購買穿戴，追擊、命中、傷害、消耗、掉落及重生用正式核心；測試所得只在記憶體，刷新/重置消失。不將此頁稱為正式雲端角色整合或多人驗收。

操作：搖桿、畫面拖動、點地移動、點怪物接近攻擊、攻擊停止、治療、切男女、半速、重置。WASD/方向鍵、Space。離開視窗/切背景清方向輸入，背景不累積模擬。15x15中央淨空，地圖延伸HUD/控制區後方。頁尾近看可比對女角側/背髮及骷髏褲裝。

驗證：art-play-browser.cjs手機實際左右/北移動、至少5種側步、互相傷害/受擊/擊殺、骷髏攻擊、切男角移動、碰撞、零pageerror與零WebSocket；21正式核心與Cloudflare建置。動作美感、頭髮長度一致性與手機手感仍待使用者驗收。
