# 暮色墓園動作試場（待實機美術驗收）

入口/art-play.html，獨立本機美術沙盒，無WebSocket、無雲端身分/存檔讀寫。正式/play仍adventure0.1.6，未替換正式人物/怪物圖集、傳輸協定或經濟判定。

使用者本輪授權：先修女角側面/背面頭髮長度一致（肩胛附近），骨白彎刀骷髏恢復破褲裝；再做實際場景移動與攻擊。女亮銀紅、男黑鋼藍、無長披風/頭盔/盾牌外觀，角色顯示高度沿ART_MOTION。新骷髏各影格保留棕色破短褲、繩帶、兩個褲管與彎刀。

男女及骷髏各24格：3向待機、2受擊、1倒下、6格側步、3格朝前/3格朝後步行、6格側向攻擊。左向鏡像，未完成八方向攻擊；橫/縱出招共用本輪側向素材但使用正式接觸時機。走路相位沿用World.actorState依位移推進，非固定站姿抖動。圖集經prepare-art-play.py依透明邊界/行分界打包到112px身體基準，runtime每張960x640，來源無損WebP保留。

src/art-play.mjs使用正式Game/createState/derive與World；地圖為獨立960x1100墓園，入口和出生點依法驗證、墓碑/墓室碰撞、三個普通骷髏點位。測試裝備用正式購買穿戴，追擊、命中、傷害、消耗、掉落及重生用正式核心；測試所得只在記憶體，刷新/重置消失。不將此頁稱為正式雲端角色整合或多人驗收。

操作：搖桿、畫面拖動、點地移動、點怪物接近攻擊、攻擊停止、治療、切男女、半速、重置。WASD/方向鍵、Space。離開視窗/切背景清方向輸入，背景不累積模擬。15x15中央淨空，地圖延伸HUD/控制區後方。頁尾近看可比對女角側/背髮及骷髏褲裝。

驗證：art-play-browser.cjs手機實際左右/北移動、至少5種側步、互相傷害/受擊/擊殺、骷髏攻擊、切男角移動、碰撞、零pageerror與零WebSocket；21正式核心與Cloudflare建置。動作美感、頭髮長度一致性與手機手感仍待使用者驗收。

## v0.2：移動閃爍、步伐與站距修正

使用者回報四項：移動畫面閃爍、滑步、待機背向、交戰過度重疊。未改格子/角色尺寸或正式/play。新步行圖集每方向六格，保留女角肩胛長髮/骷髏破短褲。步行採分層：固定上身與持武器的一致性、腿部按位移循環，側面用近遠腿陰影區分支撐半步；避免生成影格在步行半週時連持劍手都交換。步幅採88世界單位/完整循環，非按時間原地播。

原idle:right其實畫向左，metadata新增flip修正；交戰時停步面向對手。解碼時清除alpha<160的殘色，其餘設全不透明，減少半透明底色；角色/鏡頭焦點/繪製尺寸整數對齊，避免移動時一像素跳動。不是只靠降低畫質宣稱解決所有裝置閃爍。

本機試場clone的attackRange47→70（正式資料不變），角色間中心最小56。新增動態角色分離與接近時的小弧線繞行，避免被新碰撞圈卡住無法走到側向攻擊位置。腳底輔助圈可切換顯示：身體圈半徑28，攻擊圈70；圈是除錯參考，不把身高110當佔地110。傷害/命中/經濟公式仍沿核心，距離/角色碰撞為試場校準值。

art-play-spacing-browser新增連續20個移動影格頭部像素一致、右側停步、70/56設定、交戰最小間距與實際傷害。原完整移動/互攻/受擊/擊倒測試回歸通過。待使用者實機確認體感及步行美感；影格存在並不等同動畫品質驗收。

地面另發現共享World的screen-space vignette會令同一世界地點隨鏡頭位置改變明暗。試場以render-only map view略過這層暗角；真正Game.map.safe仍false、戰鬥仍運作，不修改共享World。新增同一地面取樣20個pan影格逐像素一致驗證，與頭部一起通過（unique各1）；實機仍待使用者回饋。

## v0.3：雙刀破圖與同腳循環修正

v0.2固定上身與腿部的矩形拼接會切到伸進腿部區域的刀身，混合不同影格，且原始步行圖有多格重複同一隻腳向前；增加影格數與半步陰影沒有真正修好。這版移除運行時身體拼接，每個狀態只畫一張完整影格。攻擊／移動切換不疊兩張姿勢。

新增男女與骷髏的分件素材：每方向一個完整持武器上身、遠腿大腿／小腿、近腿大腿／小腿。唯一武器完整保留在上身；分腿不包含武器。依位移相位預先合成12格完整步行，近遠腿相差半週、膝關節在擺動半週彎曲，支撐腳接地、另一腳抬起；前後向也輪流抬左右腳。側面遠腿較暗，腿的身份不靠整個下半身左右翻轉。上身先縮放一次再貼入各格，避免圖集座標重採樣造成的細微色差。這是分件關節步行提案，仍待實機美術驗收，並非完整八方向手繪動畫。原6格側向攻擊、受擊與倒下動作保留；另外修正舊裁圖混入鄰格刀尖的問題，改依完整角色連通區裁圖，攻擊格擴大224以保留伸出的刀身，角色本身不放大。

`prepare-art-play-rig.py`以alpha連通區打包15個獨立分件；`src/art-play-rig.mjs`與`bake-art-play-rig.cjs`預合成圖集，`art-play-animation.mjs`單一完整姿勢繪製。來源無損WebP及前兩版素材保留；PNG留工作區。可選重製：Python Pillow/numpy/scipy打包後，安裝Playwright並指定CHROMIUM_PATH執行bake腳本，最後將產出的PNG無損編碼為同名WebP。一般建置直接使用已打包WebP，不需要瀏覽器或Python。

運行時三圖集合計約921KB（十進位），上一版約1.58MB；關節計算只在離線打包，不增加手機每幀運算或任何WebSocket傳輸。格子、顯示身高、70/56試場站距、正式核心與雲端人物不變。

驗證：108格步行頭部有效像素一致；18格攻擊沒有獨立鄰格刀尖。男女各連續60個移動影格頭部/固定地點pixel hash各1、男角實際互攻與站距、完整移動/擊倒/切性別/零WS測試通過；21核心及2動作回歸通過。這些不取代手機美術驗收。

## v0.4：待機站姿、男角側面與接地

使用者授權修正浮起感、男角側面比例與停下併腳。男女及骷髏待機改前後腳錯開、膝微彎；男角腿甲厚度與站距一起校準，避免兩隻鞋再次合成一隻。男角側面新增較直立的上身素材，依軀幹高度而不是含刀尖的整張包圍盒縮放，維持原110.25顯示身高與黑鋼藍、短髮、無長披風。側面持劍位置朝外，避開鞋底辨識；原攻擊時機/傷害/站距不改。

分件打包時逐腿量不透明鞋底，支撐腳對齊地面、擺動腳才抬高。每個完整影格額外記錄真實鞋底接觸點，運行時畫小而貼腳的接觸陰影與較淡整體陰影。這些是視覺資料，不改角色碰撞圈。新增0.12秒收步：沿停止前的步行相位選擇兩張預合成過渡影格，再回錯腳站姿；實際位置立即停止，攻擊/受擊即時優先，不等收步完成。

新資產為`*-v4.webp`與manifest-v4、男角male-rig-v4/rig-v4及來源male-profile-v4。`prepare-art-play-profile.py`打包新側面，`bake-art-play-rig.cjs`合成待機/12步行/8收步影格，`finalize-art-play.py`記錄鞋底並無損編碼。前版分件與圖集保留，v3打包器與rig亦另檔保留。關節、鞋底掃描只在離線打包，手機仍每角色取一張完整姿勢，不增加連線訊息。三張runtime圖集約1.11MB；只在本試場首次載入，正式/play未使用。

量測驗證：9個待機方向各能辨認兩個鞋底，支撐腳在地面基準線；108步行頭部有效像素保持一致，18攻擊無鄰格刀尖；單姿勢、交替腿與收步/攻擊優先單元驗證通過。手機尺寸真browser男女連續60影格頭部與固定地面穩定，互攻、受傷、擊倒、切男女、碰撞回歸通過。比例美感與手機接地觀感仍待使用者驗收，不將技術檢查當成已獲美術認可。

重製v0.4依序執行prepare-art-play-rig.py → prepare-art-play-profile.py → bake-art-play-rig.cjs → finalize-art-play.py；一般build直接使用已打包圖集。收步browser驗證男女放開方向後角色位置不再前移、兩個視覺過渡階段有播放、停步朝向維持，零pageerror。

## v0.5：男角側面自然垂劍

只產生male-v5.webp、male-rig-v5/rig-v5、male-profile-v5來源與manifest-v5。女角與骷髏直接沿用原v4圖集，男角正/背/攻擊/受擊/倒下有效像素與v4逐格一致；不重畫其他姿勢、不改戰鬥或連線。重製只需prepare-art-play-profile.py 5 → ART_PLAY_REVISION=5 node scripts/bake-art-play-rig.cjs → finalize-art-play.py 5 male；原v4預設打包行為保留。metadata atlas指定使用的檔名，舊資產保留。

像素回歸確認非側面與其他角色保留、108步行頭部穩定/18攻擊無碎片、兩腳站姿/接地、3動作單元通過；手機尺寸browser男女停步零位置漂移、60影格頭地穩定與實際男角互攻通過。此為試場提案，側面姿勢與持劍觀感仍待使用者實機驗收。
