# 《類天堂》決策紀錄與待辦

更新：2026-10-23；目前遊戲：V0.5.17。

## 已確定
- 以 L1J-TW 3.80c 為主要公式核對依據，不憑空填數值。
- iPhone Safari 直屏、復古像素風；現階段優先遊戲性。
- 測試訓練場有骷髏、骷髏弓箭手、歐吉；訓練場加速重生屬**測試設定**，非原版重生規則。
- 歐吉被動，受到攻擊後才進入戰鬥；視覺約人物兩倍，佔一格碰撞。
- 自動喝紅水獨立於快捷欄，保留 HP 門檻設定。
- 右下角攻擊鍵較小，兩個快捷鍵位於上方；人物／裝備、背包為圓形按鈕。
- 快捷鍵未來可指定技能或可使用物品；白水目前是測試道具，數值未核實。
- 玩家升級與 EXP、強化、細劍打不死系及大型怪的差異是重點回歸測試。

## 開發流程（之後照此執行）
1. 核對來源 → 更新資料表與狀態。
2. 更新公式文件與決策紀錄。
3. 程式改用資料表，避免同一份資料在多處硬編碼。
4. 建立新版本；驗證 JS 語法與主要流程；提交 GitHub。
5. 回報：已確認、暫定、尚未實作、待 Safari 實測；附遊戲與 Actions 網址。

## 平台與優化提醒（2026-10-23）
- 目前繼續使用 HTML5/JavaScript/Canvas + GitHub Pages，優先完成騎士單機戰鬥及核心玩法，不在此階段改 Unity 或原生 App。
- 單機核心穩定、進入效能與架構優化時，主動提醒使用者評估：PWA 加入主畫面與離線快取、單一 HTML 拆分成程式模組、角色存檔備份／匯入匯出，以及是否有轉 Godot/Unity/原生 App 的必要。
