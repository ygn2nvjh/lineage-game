# online0.2延遲改善

- 狀態與命令分流；慢讀取不阻塞操作，待送移動只保留最新目標。
- 回覆以輸入epoch與房間revision檢查，避免舊狀態蓋新操作。
- 查詢起點500ms節奏，回覆慢時不再額外等500ms。
- 自己的移動採碰撞受限的位置預測，傷害／獎勵仍由伺服器判定。
- 單JOIN讀取玩家與房間，120ms內有效狀態可讀而不重寫；重要操作保留CAS及原子存檔。
- ⚙連線可測無DB ping、查看往返／排隊／app與DB耗時，複製報告不含憑證。

39項開發端核心／API測試通過（公開套件不含歷史API測試），2/4獨立瀏覽器共同通關保存通過。故障注入讓狀態卡住超過1.5秒，移動約33ms送出，沒有被讀取佇列阻塞；此為本機測試，非真實手機RTT。

目前仍HTTP＋資料庫，尚未部署WebSocket持久房間。手機450～1500ms的剩餘原因需要新診斷資料，不能把位置預測當成RTT已下降。
