# 遊戲資料與原則

正式遊戲由data/game/catalog.json提供六能力、戰鬥、物品、商店、地圖與怪物數值。保留安全村莊→買裝備補給→野外打怪升級→回城補給的最小循環。地圖中央淨空15×15格，五個導覽按鈕位於搖桿與右側快捷鍵之間。

人物13裝備槽；裝備頁採固定精細立繪，地圖維持原像素比例。倉庫僅村莊可使用且不計入背包負重，穿戴副本不能存入，領取檢查負重。背包和倉庫在單一快照交易儲存。

骷髏持彎刀；史巴托藍色、彎刀及木頭大盾；骷髏鬥士金黃、劍、鋼鐵大盾及頭盔。狼人棕毛破布短褲；暗夜狼人灰黑毛與簡易皮甲；白狼王1.2倍、高品質皮甲、雙手反握短刀。monsterAppearances.requiredTraits記錄跨風格必留特徵。

角色存於瀏覽器IndexedDB，可匯出完整備份。公開程式資料不等於玩家雲端存檔；本版沒有整合多人副本。
